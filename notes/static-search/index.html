中文搜索Pagefind

中文搜索与内容索引

本页是一篇检索示例，同时说明 Pagefind 的基本使用边界。它包含中文、英文术语和一份可直接访问的小型附件。

搜索什么

Pagefind 可以读取静态 HTML 中的文字，并为浏览器生成搜索索引。它的扩展发行版支持中文、日文、韩文分词。

可以试着搜索“中文搜索”“证据”“Agent”或“Pagefind”。标题、正文和标签会参与本知识库的检索。

动态内容如何被发现

如果重要结论只存在于 Canvas 绘图、页面脚本或网络请求返回的数据中，静态索引不一定能读取。作者应保留一段静态说明，或提供独立的检索正文。

附件与访问地址

附件可以放在条目自身的 assets 目录，例如这份 示例数据。附件有可直接访问的 URL，但不会因此自动获得全文搜索能力。

实际验收关注什么

搜索功能需要在网页中实际查询。应检查能否找到目标条目、结果是否指向正确页面，以及筛选标签后是否只保留符合条件的结果。

这篇文章用于功能演示；未给出吞吐量、延迟或检索准确率等性能结论。
